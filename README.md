# RankListVelocity

A Velocity proxy plugin to customize the `/list`, `/who`, and `/online` commands using LuckPerms groups and prefixes.

## Features
- Fully customizable list format.
- Sorts players based on LuckPerms groups (customizable order).
- Displays player prefixes from LuckPerms.
- Limits the number of displayed players and shows `(+X more)` if exceeded.
- Supports reload command `/list reload` (Requires permission `ranklist.reload`).
- Aliases: `/list`, `/who`, `/online`.

## Dependencies
- LuckPerms for Velocity (Required)
